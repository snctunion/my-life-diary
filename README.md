# MY LIFE 개인 다이어리 캘린더 — 1차 시제품

## 포함된 화면
- 로그인 화면(현재 미리보기 전용)
- 오늘 날짜 중심 홈 화면
- 월간 달력과 날짜 선택
- 일정 등록 및 개인/업무/조합 분류별 고유색 점 표시
- 일정 등록 및 매일/매주/매월/매년 반복 표시
- 다이어리 사진/파일 첨부 및 미리보기
- 다이어리 입력
- 공통 AI 스캔 화면의 파일 선택/카메라 입력 및 미리보기
- 전체 메뉴, 검색, 모바일 하단 내비게이션
- 아이폰 화면 안전 영역과 모바일 반응형 스타일

## 현재 제한
이 파일은 UI/기능 흐름을 확인하는 1차 시제품입니다.
- 로그인은 Firebase Authentication과 연결되어 있지 않습니다.
- 데이터는 현재 브라우저의 localStorage에 저장됩니다. 다른 기기와 동기화되지 않습니다.
- 공휴일 API, 실제 OCR/AI 분석, 투약 관리 DB, 차량 관리 DB, 클라우드 파일 저장은 아직 연결되지 않았습니다.
- 비밀번호를 입력해도 인증이 수행되는 것은 아니므로 실제 비밀번호를 사용하지 마세요.

## GitHub Pages 미리보기
1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`을 저장소 루트에 올립니다.
3. Settings → Pages → Deploy from a branch → `main` / `/(root)`를 선택하고 저장합니다.
4. 표시된 Pages URL에서 화면을 확인합니다.
