# MY LIFE 다이어리 업데이트

- `index.html`: 브리티시 레이싱 그린 색상 테마, Firebase 브라우저 로그인 유지, 브라우저 기반 무료 OCR, 약 정보 기록
- 유료 AI API 키는 필요하지 않습니다. OCR 실행 시 CDN 및 한국어 언어 데이터 다운로드를 위해 인터넷 연결이 필요할 수 있습니다.
- OCR은 글자만 추출합니다. 약의 효능과 복용법을 자동으로 검증하지 않으므로 처방전/약 봉투/약사 안내와 대조하고 직접 확인해야 합니다.
- 약 정보 저장은 기존 Firestore 사용자별 경로 `users/{uid}/medications/{id}`를 사용합니다. 현재 Firestore 규칙이 사용자 하위 경로에 대한 읽기/쓰기를 허용해야 합니다.
- 이 파일은 정적 검사만 수행했으며, 실제 Firebase 계정에서 배포 후 테스트는 별도로 필요합니다.
